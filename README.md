# VPN CFG

VPN-клиент для Android со встроенным ядром Xray и интерфейсом в стиле Windows 98.

Добавляйте свои серверы ссылками или подписками, выбирайте лучший по пингу и подключайтесь одной кнопкой. Сторонние клиенты не нужны: приложение само поднимает системный VPN-туннель.

## Для кого

Для тех, у кого уже есть свои серверы или подписка и нужен простой, лёгкий клиент без рекламы и аккаунтов. Приложение не предоставляет VPN-серверы.

## Возможности

- Встроенное ядро Xray: vless (Reality, TLS, WS, gRPC, XHTTP), vmess, trojan, shadowsocks, socks
- Подписки: имя, автообновление, скрытие серверов без удаления
- Пинг, сортировка, страны и города серверов, избранное, поиск
- Импорт ссылок, подписок (список или base64), Clash YAML и sing-box/xray JSON
- Гибкие настройки: DNS, MTU, IPv6, обход локальной сети, приложения в обход VPN, mux, sniffing
- Три стиля (Windows 98, Windows XP, современный) и четыре цветовые схемы
- 7 языков: русский, English, українська, español, Deutsch, Türkçe, 中文
- Журнал событий ядра и приложения с копированием
- Обновления через GitHub Releases, серверы и подписки не пропадают при обновлении

## Статус

Альфа. Встроенный туннель ещё проверяется на реальных устройствах. Hysteria2, TUIC и WireGuard пока только импортируются, подключение к ним появится позже.
